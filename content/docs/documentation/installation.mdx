---
title: Installation
description: How to install NTT Shadcn Component in your project.
---

import { siteUrl } from '@/lib/shared'
import { InstallationTabs } from '@/components/installation-tabs'

export const baseInstallationCommand = `shadcn add ${siteUrl}/<component>.json`

It doesn't matter what framework or package manager you are using. Installing NTT Shadcn Component is as simple as running the <code>{baseInstallationCommand}</code> command and replacing `<component>` with the name of the component you want to install.

The entire install process is handled by the `shadcn` CLI tool and works identically to how you would install any other Shadcn component.
